# DS-083 — Arrow keys in a menu bar with one enabled menu strand the open popup

Status: Open · Priority: P3 · 2026-11-09

## Problem

When a MenuBar's only other entry is disabled, Left or Right from a focused
row resolves to the same menu and unconditionally refocuses its trigger. The
popup stays open, but no row is focused until Down is pressed again.
Reproduced in the review copy with File (enabled) and Edit (disabled): open
File, focus "Save document", press Right. The popup remains, the File trigger
reports focus and no row does.

## Remediation

When switching resolves to the entry that is already open, keep the focused
row (or move to the first row) instead of refocusing the trigger. Add a
regression test with a single enabled menu for both directions.
