# DS-111 — InlineEdit renaming

Status: Resolved (unreleased) · 2026-11-10

## Problem

Native workbenches need to rename a label in place without changing the
committed host value while typing or losing a draft when focus moves away.

## Remediation

Add a keyed InlineEdit with application-owned draft state and typed start,
commit-request and cancel events. Use native text editing, Enter/check to
submit and Escape/close to discard. Keep focus loss explicit, respect IME,
disabled/read-only controls and host shortcuts, and compose a rename showcase.
Verify keyboard, pointer, lifecycle and accessibility behavior plus rendering
across themes and scales. Run the full qualification suite before release.

## Resolution

InlineEdit borrows the committed name and edits a host-owned draft. Named
controls support pointer, Enter/Space/F2 activation, Enter/check submission,
Escape/close cancellation and focus return. Blur retains drafts. Commit events
carry the proposal verbatim; validation and persistence stay in the host.
Read-only sessions support selection/copy and Cancel; disabled sessions retain
their draft. Compact layouts move actions below the editor.

Review found four input gaps. Focus jumped back to the label when a host
re-enabled it after saving, even if the user had moved to another field. The
second click of a double-click collapsed the selected name, a held Space typed
spaces over it, and an empty name was announced without the placeholder it
shows. Focus now returns only when nothing else took it, the starting gesture
keeps the name selected, and the placeholder is the announced value.

Twenty component tests and two showcase tests cover IME events, modal Escape
ownership, discarded passes, final text/Enter batching, double-click and held
Space starts, focus return after a held save, Unicode limits, undo isolation,
stable keyed drafts and host rejection of blank names. Rendering baselines
cover light 1×, dark 1.5× and blue 2×.

Before the review, native macOS checks passed mouse Save/Cancel and keyboard
Enter/Escape, including F2 activation, selection and focus return; the review
fixes were not checked natively. No OS IME or VoiceOver session was run.

All 23 local gates passed: 737 all-feature and 490 minimal tests,
strict Clippy in three profiles, feature combinations, documentation, SemVer,
WASM, MSRV, examples and actual archive inspection. Scope and limits are
documented in [the guide](../inline-edit.md).
