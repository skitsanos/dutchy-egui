# DS-100 — Connect DutchyAgent to OpenAI

Status: Resolved in 1.0.30 · 2026-11-09

## Problem

The offline milestone routes every prompt, including "Hi", to Scripted. Model
settings and a configured key do not produce an LLM conversation.

## Remediation

Add a Responses API provider using the existing ignored `.env` key, model and
reasoning effort. Default to OpenAI when credentials exist and retain Offline
mock as an explicit choice. Show accurate request provenance and token usage;
never silently substitute a mock for live errors. Keep secrets redacted, stream
and cancel safely, test protocol/lifecycle behavior, verify a real native "Hi"
and rerun all qualification gates before release.

## Resolution

Implemented native Responses SSE/buffered JSON over example-only ehttp and
serde_json dependencies. Host-owned routing preserves request/source identity,
bounded delivery, partial replies and retry behavior. Credentials redact Debug;
raw server errors are replaced with static feedback. Actual usage is distinct
from mock estimates. The library API and runtime dependencies are unchanged.

The native app used the existing key with `gpt-6-luna` and low effort. One real
"Hi" returned "Hi! How can I help?", reporting 22 input / 11 output tokens.
Explicit Mock selection and retained live provenance passed; the live turn was
inspected in light/dark modes. All 21 gates pass: 628 all-feature tests (32
Agent), 405 minimal tests, three strict Clippy profiles, feature/MSRV/WASM,
docs, native builds and actual archive inspection. See
[verification](../verification-dutchy-agent-live.md).

Stop cancels local delivery immediately; HTTP cancellation is cooperative and
does not guarantee immediate server cancellation or billing termination. Tools,
attachments, persistence and custom endpoints remain unsupported. No push made.
