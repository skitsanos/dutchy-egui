# DS-099 — DutchyAgent offline chat example

Status: Resolved in 1.0.30 · 2026-11-09

## Problem

Markdown and CodeBlock need a realistic chat composition, while the application
plan has no buildable offline agent example. Local future-provider settings
also need explicit secret-file exclusions.

## Remediation

Build the [offline milestone](../plan-dutchy-agent.md): deterministic scripted
provider, host-owned conversation/run state, streaming/Stop/Retry, accessible chat
UI and Markdown/code copy. Load `.env` model settings with process precedence,
retain only key presence and exclude secret files from git and package archives.
Run interaction/rendering/native and complete release-qualification checks.

## Resolution

Implemented the dependency-free scripted provider, independent conversations,
streaming/Stop/Retry, accessible composer, simulated errors, settings and
Markdown/code-copy composition. A regression reproduced short code clipping in
the transcript's nested scroll layout; natural message sizing fixes it without
changing library APIs. Twenty example tests cover state, input, IME, copy,
configuration, cancellation and rendering. All 21 local gates pass, including
616 all-feature tests, strict Clippy, feature/MSRV/WASM checks and archive
inspection. Native macOS light/dark flows pass. Secret-file exclusion is checked
with a nested sentinel. See [verification](../verification-dutchy-agent.md).
At initial qualification, live transport and real usage were deferred. They are
now covered by [DS-100](DS-100.md). Persistence remains deferred; no push made.
