# DS-089 — Shortcut editing needs a native control

Status: Resolved in 1.0.28 · 2026-11-09

## Problem

Applications cannot capture and validate a replacement chord with a Dutchy control.

## Remediation

Add KeyRecorder with portable chords, cancellation, clearing, conflict feedback and dispatch suppression.
Keep APIs additive, state with the host, dependencies minimal, code modular,
and verify keyboard/accessibility, themes/scales and disabled states.

## Resolution

Added KeyRecorder with an explicit Clear control, portable Command/Control
capture, reserved-binding rejection and an accessible conflict alert. Capture
blocks registry commands; repeats, IME and modifier-only input cannot commit.
Escape cancels without closing the enclosing Drawer; Tab exits normally.
Tests cover cancellation, disabled/read-only state and discarded-pass input
replay. Native rebinding/conflict checks and all local gates pass; see
[verification](../verification-command-workflow.md). Tab/Escape remain reserved
for navigation; OS-reserved chords may never reach the app.
Included in the [1.0.28 release qualification](../verification-release-1.0.28.md).
