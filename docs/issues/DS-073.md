# DS-073 — Richer menus and application command surfaces

Status: Resolved locally (Unreleased) · 2026-11-08

## Problem

Menus currently expose flat commands only. Applications need checked actions,
nested command groups and a menu bar that can share commands with Toolbar.
Repeated application code otherwise has to implement popup placement, focus,
checked-state paint and dismissal independently.

## Remediation

Extend MenuItem with controlled checked state and borrowed submenu entries.
Return typed requests without executing commands or persisting application
values. Reuse Dropdown for anchors, introduce an in-window MenuBar, and let
Toolbar items open the same menus. Preserve stable keys, disabled inheritance,
keyboard navigation, focus return, native accessibility and token geometry.
Keep the implementation modular and dependency-free. The acceptance plan is
in [richer menus](../richer-menus.md).

## Resolution

Implemented MenuEvent, checked leaf actions, borrowed recursive submenus,
MenuBar/MenuBarItem/MenuBarState and ToolbarItem menu buttons. Branch keys
never execute. Checked values remain host snapshots, including when the host
rejects a change. Native menu/checkbox roles expose expanded/controlled state
and real child-menu containment. Popup placement, pointer transitions, nested
Escape/Left, Tab exit and dynamic focus repair share the existing primitives.

Review fixed Escape clearing focus before dispatch, stale switching requests
surviving sizing passes, explicit assistive focus on inactive roving items,
submenu accessibility containment and popup anchoring beneath the menu bar.
Focused regressions cover these cases. Canal Studio appears on Menus and
Toolbars and shares view settings/export requests across both surfaces.

All 506 all-feature and 355 minimal-feature tests pass, plus formatting, all
three Clippy profiles, strict docs, WASM, partial-feature checks, Rust 1.95 and
native build. Nine new image baselines span three themes/scales; all 119
previous snapshots/screenshots are unchanged. The actual crate archive passes
inspection without new dependencies or protected media/IDE artifacts.

Native macOS checks confirm linked checked states, rejected requests, nested
navigation/containment, dismissal and toolbar export feedback. Platform and
native focus observations are explicit in
[verification](../verification-richer-menus.md). Radio/mixed checks, mnemonics
and OS menu integration remain outside scope. No release, commit or push was
performed; package version stays 1.0.25.

These totals describe initial DS-073 qualification. The subsequent native Tab
and cascade review is tracked by [DS-074](DS-074.md), [DS-075](DS-075.md) and
their [verification report](../verification-menu-polish.md).
