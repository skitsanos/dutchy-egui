# DS-096 — Roadmap lost an item and coverage omits the command controls

Status: Resolved in 1.0.28 (found in its review) · Priority: P4 · 2026-11-09

## Problem

The 1.0.28 roadmap rewrite removed the whole "Command plumbing" entry. That
entry promised a DataTable column-visibility menu built from checked actions,
alongside SplitButton and KeyRecorder. The menu was not part of the 1.0.28
plan. It survived only as a generic "column chooser menu" under DataTable
extensions, without the link to checked commands or a note that it was
deferred. The first review report said it was mentioned nowhere; that search
missed the "column chooser" wording.

The coverage page described the new work in one paragraph but added no table
rows for CommandRegistry, SplitButton and KeyRecorder. MenuBar and Toolbar
each have a row with supported scope and remaining limits.

## Remediation

Restore the column-visibility menu as a roadmap item, or record why it was
dropped. Add coverage rows for the three new APIs with their supported scope
and the limits already listed in the command guide.

## Resolution

The DataTable roadmap bullet now describes the column chooser as checked
commands from a host CommandRegistry, deferred from the 1.0.28 work. Coverage
gains CommandRegistry, SplitButton and KeyRecorder rows with their supported
scope and limits, and the Dropdowns row notes nested palette search.
