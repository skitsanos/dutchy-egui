# DS-087 — Shared command metadata and keyboard routing

Status: Resolved in 1.0.28 · 2026-11-09

## Problem

Menus expose labels without bindings; palette and applications consume shortcuts separately.

## Remediation

Add a host-owned CommandRegistry, typed requests, platform formatting, scoped dispatch and conflict reporting.
Keep APIs additive, state with the host, dependencies minimal, code modular,
and verify keyboard/accessibility, themes/scales and disabled states.

## Resolution

Added typed metadata and requests, exact event-modifier dispatch, focus scopes,
conflict diagnostics and shared menu/toolbar hints. Enabled/checked values and
execution remain with the host. Editing, IME, recorder and overlay input are
protected; repeated/discarded frame passes cannot execute a command twice or
leak its consumed chord. Tests cover scopes, platform aliases, conflicts,
rebinding, input policy and replay. All local gates pass. Single chords only;
custom host overlays must gate dispatch themselves.
