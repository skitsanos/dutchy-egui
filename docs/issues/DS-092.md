# DS-092 — Release gates are manual

Status: Resolved in 1.0.28 · 2026-11-09

## Problem

The repository has no CI workflow enforcing the qualification checks.

## Remediation

Add CI for format, tests/rendering, Clippy profiles, feature/WASM/MSRV checks and package inspection.
Keep APIs additive, state with the host, dependencies minimal, code modular,
and verify keyboard/accessibility, themes/scales and disabled states.

## Resolution

Added a fail-fast qualification script and an inspector for the actual crate
archive: approved paths, matching source bytes, font/third-party licences and
packaged relative links. CI runs the matrix with Linux software Vulkan and
library checks on macOS/Windows. The official checkout Action is commit-pinned,
permissions are read-only and credentials are not persisted. All 18 local gates,
actionlint and shell syntax checks pass. The first hosted run, on the 1.0.28
push, passed. No publication step.
