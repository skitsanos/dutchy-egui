# DS-121 — Removable and toggleable chips

Status: Resolved in 1.6.0 · 2026-11-11

## Problem

Filter and tag controls need a compact square chip with an optional toggle
body and an independently operable remove button.

## Remediation

Add a keyed Chip with host-owned selection and removal requests. Demonstrate
status filtering and tag removal in Showcase.

## Resolution

Chip exposes independent toggle and remove responses with stable IDs, native
keyboard activation, accessible names and selection state. Showcase applies
selection to a document filter and moves focus to Restore tags after a focused
remove button is deleted.

Regression tests cover host ownership, separate hit targets and Tab stops,
direct and inherited disable during a pending click, narrow reflow and
segment-local hover paint in light 1× and dark 2×.
Native macOS Showcase checks verified mouse and keyboard filtering, tag
removal, focus recovery, and restoration.
