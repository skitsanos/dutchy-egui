# DS-005 — Add application form controls and validation

Status: Resolved · 2026-11-06

## Problem

The visual-proof release cannot compose a real application form. Text inputs,
passwords, textarea, checkbox, radio selection, select menus, and field feedback
need consistent geometry, stable IDs, keyboard operation, and accessible labels.
Validation needs explicit triggers and protection against stale async results.

## Remediation

Build modular controls over egui primitives with shared size tokens. Add a Field
wrapper for labels, required/help/error/pending/success presentation and metadata.
Provide pure validation rules and host-owned field state for change/blur/submit
triggers. Let applications execute async work and accept only the current request
ticket. Add an interactive showcase form, behavior tests, and rendered evidence.
Keep egui as the sole direct runtime dependency.

## Resolution

Implemented Input/password, Textarea, Checkbox, RadioGroup, Select, Field, and
validation rules/state in 1.0.1 on `ticket/form-controls-validation`. Values,
submission, and async execution remain host-owned. No runtime dependencies were
added. Native dropdown testing exposed unnamed options when overriding egui's
option role; retaining its selectable-button semantics restored macOS names.

All 35 integration tests and one doctest pass, including keyboard selection,
label focus, read-only/password behavior, Unicode limits, trigger timing, stale
async rejection, stable IDs, and the example's validate/reset flow. All required
Clippy configurations pass. Light/dark render baselines at 1x/1.5x and desktop/
narrow layouts were reviewed; native Glow and macOS accessibility were inspected.
See [verification](../verification-forms.md) and the [API guide](../forms.md).

Interactive textarea resizing remains planned. Choice controls use change/submit
validation: radio-group blur is not aggregated, and select blur concerns its
trigger. Running screen-reader testing remains outstanding. Source-palette
contrast limitations remain in DS-003. Other application essentials are planned.
