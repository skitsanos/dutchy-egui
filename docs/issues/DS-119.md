# DS-119 — Offline icon subset for DutchyMail

Status: Resolved (unreleased) · 2026-11-11

## Problem

DutchyMail needs a way to compare its original Toolbar icons with a reusable
pack while preserving first-launch rendering offline.

## Remediation

Subset Phosphor Regular v2.1.2 to the four Toolbar glyphs and generate the Rust
map from the same pinned release. Register an example-specific font family
only when the host opts in, and keep the existing painters as fallback.

## Resolution

The 1,920-byte subset is embedded in the example and opted into with
`DUTCHY_MAIL_ICONS=phosphor`. Its glyphs inherit control color and leave
interaction and accessible names with the Toolbar. The asset preparation
script checks source hashes and preserves the MIT notice.

Archive uses an icon-only Toolbar button with its name and shortcut in the
tooltip.

All DutchyMail tests passed with process networking denied. Rendering tests
cover the four named controls at light 1× and dark 2×, and compare the
fallback's Toolbar pixels with the default after removing the icon family.
