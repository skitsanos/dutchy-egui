# DS-090 — Command search omits nested menu leaves

Status: Resolved in 1.0.28 · 2026-11-09

## Problem

CommandPalette ignores submenu descendants, hiding application actions from search.

## Remediation

Flatten nested leaves with stable path identity, ancestor availability and searchable breadcrumb context.
Keep APIs additive, state with the host, dependencies minimal, code modular,
and verify keyboard/accessibility, themes/scales and disabled states.

## Resolution

CommandPalette searches nested leaves using every query word across their
breadcrumb and label. Full keyed paths preserve identity through renames and
distinguish equal leaf keys in separate branches. Disabled ancestors propagate;
branches and empty submenus never execute. Flat items and SearchableSelect keep
their existing behavior. Interaction tests and native nested PNG discovery
pass. Matching remains
case-insensitive substring search, without fuzzy ranking.
