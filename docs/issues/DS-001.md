# DS-001 — Freeze the port's reference contract

Status: Resolved · 2026-11-05

## Problem

Web documentation mixes older neutral colors with the current warm palette,
includes soft shadows, and describes a dark theme absent from the stylesheet.
Control heights vary. A component count alone does not define parity.

## Remediation

Record the source revision in `docs/plan.md`. Take current CSS/rendered output
as the appearance reference; use component documentation and behavior as the
functional reference. Follow the user's zero-radius/no-blur brief. Set shared
control heights to 32/48/56 logical points. Use documented dark neutrals with
explicit semantic mappings. Track all 27 registry groups in `docs/coverage.md`.

## Resolution

The implementation plan and reference decisions are saved. Source-specific
limitations and intentional differences remain explicit in the coverage matrix
and individual ledger entries. The crate does not require the web checkout.
