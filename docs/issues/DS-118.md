# DS-118 — Shared commands for DutchyMail menus

Status: Resolved (unreleased) · 2026-11-11

## Problem

DutchyMail defined its toolbar actions and shortcuts separately. It had no
application menu bar or context actions for message rows.

## Remediation

Use one host-owned CommandRegistry for the MenuBar, context menus, Toolbar,
keyboard dispatch and hints. Capture message keys when a context menu opens
and validate the targets against the current view before executing.

## Resolution

The Mailbox and Message menus share commands with the Toolbar and shortcuts.
Right-click and Shift+F10 open message context actions. A selected row targets
the selection, while an unselected row targets only itself and leaves the
reader unchanged. The Toolbar uses two original local glyphs for Archive and
Read / unread.

Five integration tests cover shared metadata and dispatch, message targeting,
keyboard focus return and dismissal when filtering. The light 1× and dark 2×
snapshots cover the new layout. Native macOS input verified Mailbox Search,
right-click, Escape and Shift+F10 followed by Archive.
