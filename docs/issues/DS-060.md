# DS-060 — Add picture cards with independent preview and saved actions

Status: Resolved in 1.0.23 · 2026-11-08

## Problem

Card and Image are composable but do not expose the Foliopress picture-card
pattern: artwork, category, title, description, contextual preview action and
an independent saved toggle. Whole-card click wrappers risk capturing save or
retry actions and hiding primary actions from keyboard users.

## Remediation

Add MediaCard with host-owned source/saved state and explicit open/save requests.
Reuse the native image-loading, status, aspect and retry pipeline, a flat bordered
Card, and shared typography/spacing. Give preview, metadata, saved and retry
targets independent native interactions and names. Include the search/sort/filter
artwork-browser showcase and meaningful interaction/rendering tests.

## Resolution

MediaCard now composes Card and the existing Image pipeline, with native
preview, metadata, saved and retry targets. Save returns a desired state and
never opens the card. Native macOS verified search/sort/filter composition,
save/unsave, empty/reset, preview and Escape/focus return. New tests cover
independent actions, keyboard preview visibility, source status, stable IDs,
disabled parents and manual scrolling without snapback.

Three theme/scale baselines and desktop/narrow showcase renders were reviewed.
All checks pass: 435/324 tests, formatting, three Clippy configurations,
rustdoc, native build and both WASM configurations. See
[verification evidence](../verification-media-card-search-input.md) and the
[composition guide](../media-card-search-input.md). No extra dependency; this
implementation is included in repository release 1.0.23.
