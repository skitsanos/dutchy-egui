# DS-124 — Fuzzy scorer and matched-glyph emphasis

Status: Resolved (unreleased) · 2026-11-11

## Problem

CommandPalette and SearchableSelect filtered case-insensitive substrings and
listed results in host order. An abbreviation such as "crp" found nothing, a
weak match could sit above an exact one, and nothing showed why a result
matched. Hosts filtering their own lists had no shared scorer, so DutchyMail
searched by whole words.

## Remediation

Add a small repository-owned scorer with no dependency. Rank the two built-in
search surfaces with it and mark matched glyphs through a `Text` builder that
hosts can use as well. Keep List type-ahead a prefix search: list boxes
conventionally work that way, and it is keyboard behavior hosts rely on.

## Resolution

`fuzzy_match(query, text)` returns a score and the matched byte ranges, or
`None`. Every whitespace-separated word must match as an in-order subsequence,
in any word order and ignoring case. The scorer finds the best placement and
rewards runs, word and camel-case starts and early matches. It scores the
first 256 characters and has no accent folding or typo tolerance.
`FuzzyMatch::merge` combines the words of one field, and `Text::highlight`
draws ranges in bold without changing the accessible name.

CommandPalette and SearchableSelect match the label first and the group at
half score. With a query, groups follow their best result and results follow
their score; a blank query keeps the host order. This changes which result
Enter activates for a given query, so the changelog lists it as a behavior
change. The selected option drops its bold label while a query marks matches.
DutchyMail ranks sender and subject matches, marks them, and drops a message
when a word scores under three quarters of that word's best score.

Tests cover matching rules, ranking order, byte ranges on multi-byte text, the
256-character bound, palette and select ordering, Enter on the best match,
group headings and highlight sections. The widget tests failed before the
change. Renders in light 1× and dark 2× show the bold glyphs on active,
disabled and selected rows. Without `bundled-fonts` there is one weight, so
nothing is marked. The native window was not exercised.
