# DS-035 — Menus, dropdowns, and page navigation: minor deviations

Status: Resolved · 2026-11-07

## Problem

Low-severity differences from the live components that
`docs/menus-dropdowns.md` and `docs/breadcrumbs-pagination.md` do not record:

- Compact pagination summary: the web renders "Page **3** of **12**" with
  bold foreground numbers on a muted base; `summary` in
  `src/widgets/pagination/paint.rs` paints the whole string small, regular,
  and muted.
- Resting page-number color: the live component inherits the foreground and
  the Markdown spec says muted-foreground; the port uses muted at rest and
  foreground on hover. The guide records the live 40-point geometry and the
  primary current-page fill but not which source governs text color.
- Collapsed-ancestor ellipsis button: the web uses the border token at rest;
  `src/widgets/breadcrumbs/paint.rs` strokes it with muted-foreground at rest
  (primary on hover and focus in both).
- Command palette header: the web uses a borderless transparent 14-point input
  with a leading search glyph inside a 16-point padded header with a 2-point
  divider; `src/widgets/command_palette.rs` places the standard bordered
  48-point `Input` with 16-point text and no glyph.
- Shortcut hints on a highlighted row switch to the on-primary foreground
  (`src/widgets/menu/paint.rs`); the live row keeps muted-foreground. Better
  contrast on the primary fill, but undocumented.
- Decorative glyphs: menu icon slots are 20 points (`ICON_SIZE`) against the
  web's 16; the breadcrumb slash is a 1-point diagonal across the 16-point
  box and chevrons are 8-point, 2-point strokes, against the web's
  typographic "/" and thinner SVG chevrons.
- `Dropdown` caps its popup with `COMMANDS_HEIGHT` (320, documented as the
  command result-list height in `src/tokens/menu.rs`); the web dropdown has
  no cap. Harmless, but the token name no longer describes its use.

Row geometry, group headings, separators, widths, backdrop opacity, disabled
alpha, and the documented omission of the web's drop shadow all match.

## Remediation

Bold the numbers in the compact summary (two sections in one `LayoutJob`),
choose and record one source for the resting number color, use the border
token for the resting ellipsis stroke, give the palette a borderless header
input with a search glyph or document the shared `Input`, keep or revert the
on-primary hint color as a recorded decision, and rename or split the dropdown
height token. Refresh the menu and navigation baselines after changes.

## Resolution

Resolved in 1.0.16. The compact summary lays out "Page", the current page,
"of" and the total as four sections with bold foreground numbers on a muted
base; page numbers rest on the foreground like the live component while
direction controls rest muted (`tests/pagination.rs`); the collapsed-ancestor
button rests on the border token (`tests/breadcrumbs.rs`); the dropdown cap
has its own `DROPDOWN_MAX_HEIGHT` token. `docs/menus-dropdowns.md` and
`docs/breadcrumbs-pagination.md` record the shared palette input, the
on-primary hint color, the 20-point icon slots and the breadcrumb glyphs as
decisions. The navigation baselines were refreshed.
