# DS-054 — Renovate onboarding awaits release integration

Status: Resolved in the 1.0.20 release preparation · 2026-11-07

## Problem

Renovate's onboarding PR #1 was still open, so dependency update proposals had
not started. Its only change is a six-line `renovate.json` extending
`config:recommended`; it does not upgrade a crate. The project requires a
version increment for every push to main, so automatic merging would bypass
the release workflow.

## Remediation

Review the complete PR at `d4b6beb63274fb046b8a972eecc4239745faf08d`, verify
that it merges without conflicts, and incorporate its original commit into
the same push as 1.0.20. Explicitly set `automerge: false`. Keep dependencies
unchanged; review future upgrade PRs against current stable releases and run
the required Rust checks before their versioned releases.

## Resolution

The configuration uses the documented recommended preset and adds no runtime
dependency. GitHub reports its security check as successful. Validate the final
JSON and merge ancestry before pushing; record the live PR and cleanup results
in the local 1.0.20 maintenance receipt. The Rust and rendering qualification
is recorded in `docs/verification-post-review-1.0.20.md`.

[recommended preset](https://docs.renovatebot.com/presets-config/#configrecommended),
