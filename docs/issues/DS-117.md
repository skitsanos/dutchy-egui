# DS-117 — DutchyMail selection and move Undo

Status: Resolved (unreleased) · 2026-11-11

## Problem

A search with no matches left the previous selection in the reader and let
the Archive shortcut move mail hidden by the filter. Undo on an older toast
could reverse a subsequent move of the same message.

## Remediation

Clear list state when the empty view replaces the message list. Record which
move is current for each message so Undo can restore only eligible messages,
even when a later move ends in the same folder.

## Resolution

The empty view clears the selection and reader, and clearing search does
not revive it. Undo skips messages with a newer move and can unwind valid
moves in reverse order. Two interaction regressions reproduced the original
failures, and model tests cover partial batches and revisiting a folder.
