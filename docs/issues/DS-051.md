# DS-051 — Calendar entry and navigation can lose valid focus

Status: Resolved locally · 2026-11-07

## Problem

An empty bounded picker could anchor on an out-of-range supplied `today`.
Arrows and page keys could focus disabled dates and lose keyboard navigation.
The initial focus request could also expire during the popup's sizing pass.

## Remediation

Clamp anchors and navigation to inclusive bounds. Disable month navigation
when the destination month cannot intersect the range. Transfer focus if host
bounds change, and request initial day focus once after the sizing pass.
Opening or moving focus never commits a value.

## Resolution

`tests/calendar_limits.rs` verifies valid initial focus without a commit,
Left at the minimum, PageDown at the maximum, and Enter selection. These
regressions failed before the fix. Native opening, Right/Enter selection and
Escape returning to the trigger were also verified. Existing month/day input
and rendering checks pass. Reversed host bounds remain invalid configuration.
