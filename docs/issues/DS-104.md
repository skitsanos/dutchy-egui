# DS-104 — Text sinks to the bottom of wrapping rows

Status: Resolved in 1.0.30 (found in its review) · Priority: P2 · 2026-11-09

## Problem

In a wrapping horizontal layout, such as `Flex::row(..).wrap(true)` or
`Ui::horizontal_wrapped`, `Text` sits at the bottom of the row while buttons
and badges center in it. The DutchyAgent heading shows its subtitle about
14 points below the neighboring button label, and the composer hint sits
below the center of the Send button.

egui lays out a label in a wrapping row so that its first line continues
after the previous widget, and it raises that line to the row height. The
vertical position inside the taller line comes from each section's
`TextFormat::valign`. egui's `RichText` sets it from `Ui::text_valign`, which
is centered by default. `Text::layout_job` leaves `TextFormat::default()`,
whose `valign` is bottom.

## Remediation

When `Text` is added to a `Ui`, align every section with `Ui::text_valign`,
matching egui's own labels. `Text::layout_job` keeps its current output for
callers that build galleys themselves. A line whose height equals the text
line height is unaffected, so the change applies only where egui raises the
first row. Add a geometry test that fails before the fix, then review every
snapshot that changes.

## Resolution

Applying the alignment to every `Text` moved glyphs by fractions of a pixel in
about forty snapshots, because epaint applies `valign` to the rounded row height
minus the line height. The fix is therefore limited to left-to-right wrapping
layouts, the only place egui raises the first row.

A new layout test failed by 14 points before the fix, the offset seen in the
Agent baselines, and passes after it for both `Flex` and `horizontal_wrapped`.
Fourteen snapshots changed, each reviewed: the nine DutchyAgent captures, the
DutchyTodo header (title and version now center on the Commands row) and three
lightbox captures (the "1 / 6" counter now centers on its arrow buttons). No
other snapshot changed. Text continuing across rows is unchanged; the layout
guide documents `Ui::end_row` for keeping short copy whole.
