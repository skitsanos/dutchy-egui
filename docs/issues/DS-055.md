# DS-055 — Upgrade the native file-dialog demonstration to rfd 0.18.0

Status: Resolved in 1.0.21 · 2026-11-07

## Problem

Renovate PR #2 proposes rfd 0.18.0 in place of 0.17.2. The showcase uses
native multi-file selection and Scribble Save As; these flows need verification
against the new dependency before release. The library must keep rfd out of
its runtime dependency graph.

## Remediation

Merge the original PR commit `fa2f655f9ba82f7df422eeae9b178219f08863e7`,
bump the package and lockfile to 1.0.21, and update current integration guides
and third-party notices. Confirm the registry version and upstream changes,
then run the full check matrix, native picker acceptance and package checks.

The crates.io API confirms 0.18.0 is the latest stable, non-yanked release.
Its Rust 1.92 requirement is below this project's Rust 1.95 minimum. The used
FileDialog builder, filters, `pick_files` and `save_file` calls are unchanged;
no adapter changes or additional runtime crates are needed. The lockfile adds
the 0.3.2 uniform-type-identifiers binding and consolidates pollster versions.

## Resolution

All required checks passed, along with no-default tests, rustdoc, WASM and the
native showcase build. Native picker selection/cancellation and SVG/PNG
Save As preserve data and restore focus. Export readback validates three SVG
strokes with 23 points and a 1200 × 400 PNG. Release qualification, packaging
and platform limits are recorded in
[the rfd upgrade verification](../verification-rfd-1.0.21.md). Ignore `/media/`
at the user's request; preserve its unrelated video work and storyboard outputs
during staging and post-push cleanup.
