# DS-069 — Align landing-page claims and review status with the public API

Status: Resolved in 1.0.24 · Priority: P3 · 2026-11-08

## Problem

README says every control implements `egui::Widget` and returns a native
`Response`. Several public components use `.show(...)` and return structured
results, including Toolbar, MediaCard and DataTable. A developer following the
blanket statement cannot add those builders with `ui.add(...)`. The statement
that egui is the only runtime dependency also needs to say "by default":
`url-images` and `png-export` add optional runtime dependencies.

The earlier review report's Result still says DS-063–065 "remain open", despite
the later fix section and resolved ledger entries. The original actions report
uses present tense for the old 42-line README; the current developer landing
page is 118 lines. The later report also refers to a "final matrix below" that
is not present after its DS-066 paragraph. Historical evidence is useful, but
its dates/scope need to be explicit.

## Remediation

Keep the new landing-page structure and screenshots. Describe native widget
and builder/composite APIs accurately, qualify the default dependency claim,
and frame earlier verification counts/README size as historical evidence.
Make the review's initial findings and later resolutions unambiguous; link the
current qualification record instead of a missing matrix.

## Resolution

README distinguishes `Widget` controls from `.show(...)` composites, describes
host-owned durable state, and lists the actual feature-gated dependencies,
including the integrated default Markdown parser. The developer landing-page
layout and existing screenshots are retained. Setup and third-party notices
agree with Cargo features.

The earlier reports were updated to label their original findings, README size
and test counts as historical, distinguish later fixes, and point to the
current combined qualification instead of an absent matrix. Relative
documentation links were checked; no release claim or version bump was added.
