# DS-123 — Tag input

Status: Resolved in 1.8.0 · 2026-11-11

## Problem

Applications need a reusable editor for a draft tag and existing keyed tags.
Hosts need to validate additions and decide when to apply removal requests.

## Remediation

Compose removable Chips and the Dutchy text input. Return typed requests
while the host owns the draft and tag list. Demonstrate keyboard editing,
removal, and host validation in Showcase.

## Resolution

TagInput emits a trimmed addition or a keyed removal and keeps the draft and
tag list under host control. It supports fixed tags, native Tab and remove
button activation, and Backspace from an empty draft. Showcase validates
duplicates, keeps rejected drafts editable, and clears stale feedback when
the conflicting tag is removed.

Focused tests cover a declined request, same-frame text and Enter, IME,
disabled transitions, and wrapped rendering in light 1× and dark 2×.
Native macOS Showcase confirmed typed entry and Return, empty-draft Backspace,
duplicate rejection, and Shift+Tab and Space on a remove button.
