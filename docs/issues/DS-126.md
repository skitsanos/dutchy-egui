# DS-126 — MultiSelect

Status: Resolved in 1.10.0 · 2026-11-11

## Problem

Applications that filter by several catalog values need searchable choices
and a way to review or remove the selected values.

## Remediation

Compose the existing fuzzy results and removable Chips. Read the host's
selection and emit typed requests for the host to accept or decline. Add a
Showcase page that filters assets by the chosen media types.

## Resolution

MultiSelect shares the option popup and fuzzy ranking with SearchableSelect.
Result activation requests a selection change and keeps the query and results
open. Removable Chips request deselection and return focus to the query. The
host supplies the selected values each frame, and selected disabled choices
appear as fixed Chips.

Tests cover declined requests, keyboard navigation, held Enter, IME, disabled
transitions, multiselect accessibility semantics, and wrapping in light 1× and
dark 2×. The native macOS Showcase confirmed that `prn` finds Prints, Return
adds it, and pointer and keyboard removal update the asset filter.
