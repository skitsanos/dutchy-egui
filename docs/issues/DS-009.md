# DS-009 — Add tooltips and layout composition

Status: Resolved · 2026-11-06

## Problem

Application essentials need concise hover/keyboard help and reusable spacing,
centered content, and responsive columns. Helpers must preserve native control
semantics and child identity as content reflows, without importing helper crates.

## Remediation

Style native tooltip popups with shared tokens; add focus presentation, accessible
descriptions, and Escape dismissal. Compose native layouts into Flex, Container,
and keyed ResponsiveGrid. Integrate public APIs into the form and a workspace
settings/dashboard example. Verify interactions, identity, wrapping, native
behavior, packaging, and rendering across display scales/themes.

## Resolution

Implemented on `ticket/tooltips-layout` (1.0.5), without new dependencies.
Tooltips preserve names and field guidance, use native timing/placement, support
disabled hover and keyboard presentation, and dismiss on Escape without consuming
the key. Native egui focus policy remains intact. Flex, centered Container, and
keyed ResponsiveGrid use shared tokens and preserve host-owned controls through
reflow/reordering. The existing form and new workspace example use public APIs.

All 76 integration tests and one doctest pass, as do all required Clippy
configurations. No-default-feature tests, WASM library compilation, rustdoc,
packaging, and the independent packaged-example check pass. Reviewed light/dark
rendering at 1x/1.5x/2x, desktop/narrow layouts, native tooltip Tab/Escape behavior,
merged help, settings edits/save, and responsive composition. All source files
remain below 400 lines. See the [guide](../tooltips-layout.md) and
[verification](../verification-layout.md).

Core application essentials are complete. CSS baseline/distribution/column
wrapping and the HTML shell are outside this native layout scope. Source-palette
contrast remains in DS-003. Running screen-reader, Windows/Linux GUI, and minimum
toolchain validation remain outstanding. The 1.0.4 release is on main as
`c8c8747`; this record was captured before the 1.0.5 release commit.
