# DS-002 — Implement and verify the visual proof

Status: Resolved · 2026-11-05

## Problem

The empty repository cannot yet demonstrate Dutchy typography, theme fidelity,
interaction states, or independent library packaging.

## Remediation

Implement shared tokens, themes, static font faces, LayoutJob typography, five
button variants, eight badge variants, and the square spinner. Add a modular
native showcase and automated interaction/rendering checks. Keep the direct
runtime dependency list to egui. Start the package at 1.0.0.

## Resolution

Implemented at 1.0.0 using egui/eframe/egui_kittest 0.37.0. Sixteen integration
tests and one doctest pass, including pointer/keyboard activation, disabled and
loading state, close-only badge dismissal, font metrics, wrapping, state
isolation, animation scheduling, theme navigation, and rendering baselines.
No-default-feature tests and all required Clippy configurations pass. WASM
library compilation, rustdoc with warnings denied, and package verification pass.

The real macOS Glow showcase was opened and checked for action activation,
purple/dark switching, badge dismissal/restoration, and return to orange/light.
Desktop/narrow WGPU renders and five snapshots were visually inspected. Source
contrast limitations remain open in DS-003.
