# DS-061 — Keep the README essential and make docs discoverable

Status: Resolved in 1.0.23 · 2026-11-08

## Problem

The README grew to 369 lines, mixing release narratives, detailed component
contracts, developer commands and platform reports. This makes basic setup hard
to find and duplicates documentation that already belongs under docs.

## Remediation

Keep purpose, a minimal setup example, showcase command and documentation/license
links in README. Move detailed setup/theme/font/feature instructions and release/
verification guidance into focused docs. Add a documentation index linking the
existing component guides. Record this convention in AGENTS.md.

## Resolution

README now contains the short entry point, without version-by-version narratives
or a component catalogue. The new docs index, getting-started and development
guides preserve useful setup and maintenance guidance. Release history stays in
CHANGELOG.md. Links and package inclusion are checked with the 1.0.23 release.
