# DS-058 — Render Markdown from Dutchy tokens

Status: Resolved locally · 2026-11-08

## Problem

Applications have no way to show documentation, release notes or generated
help inside a Dutchy UI. The standard egui Markdown viewer styles from egui's
`Style`: headings scale off one text style without the display face, tracking
or uppercase rules, code blocks and quotes use egui frames, and it adds a
widget crate with its own egui version coupling. Neither matches the design
system nor the dependency policy.

## Remediation

Parse with pulldown-cmark 0.13.6 (MIT, default features off: `bitflags`,
`memchr`, `unicase`; the first two were already locked, all three are current)
behind a default `markdown` feature. Build a block/inline tree once per source
change and render it from repository-owned code: `Text` typography per heading
level, paragraphs as one galley with links as focusable Link widgets over
their glyph rows, square list markers and mono numbering, read-only task
boxes, accent-rule quotes and status callouts, content-sized tables that
shrink above their widest words, `Image` figures, and a new public `CodeBlock`
with language label, native copy, line numbers, host highlighting and
horizontal scrolling. Report every activated link; open external links and
scroll to fragments by default, or report only.

## Resolution

Ten model unit tests, nine interaction tests and two showcase tests pass;
six rendering baselines (light 1x, dark 1.5x, purple 2x, narrow, link focus,
copy hover) were reviewed. Review corrected two findings: the ghost copy
control's hover vanished on the muted surface (now outline), and shrinking
columns broke words such as "VALUE" mid-word (columns now stop at their widest
word). The showcase gains a Markdown page with host-logged links, heading
demotion and a live source editor. Footnotes, math and HTML remain outside the
supported scope and are documented in [the guide](../markdown.md). See
[the verification record](../verification-markdown.md).
