# DS-004 — Styled buttons clipped in wrapping layouts

Status: Resolved · 2026-11-05

## Problem

The first button wrapper entered a child style scope before allocating its
control width. In a wrapping row, the parent could not move the complete widget
to the next row. Narrow layouts overflowed; table cells collapsed labels to
ellipses. Visual inspection exposed behavior missed by the initial click tests.

## Remediation

Measure the label and optional spinner, reserve the natural control width, then
create the isolated style scope. Continue using egui's button implementation for
activation and accessibility. Add a narrow-column regression asserting natural
width, row wrapping, and containment; check the real showcase at 480 points.

## Resolution

The wrapper now allocates before entering its child UI. Desktop/narrow showcase
renders and focused state snapshots were inspected after the change. The
regression prevents silent truncation and horizontal overflow from returning.
