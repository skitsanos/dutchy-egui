# DS-091 — Examples duplicate command metadata and routing

Status: Resolved in 1.0.28 · 2026-11-09

## Problem

Todo and Canal Studio do not share bindings, labels and action availability across command surfaces.

## Remediation

Adopt the registry, SplitButton, KeyRecorder and nested search in the existing examples.
Keep APIs additive, state with the host, dependencies minimal, code modular,
and verify keyboard/accessibility, themes/scales and disabled states.

## Resolution

Todo now shares New/Search/file/palette metadata, exposes live shortcut editing
and offers file alternatives through its New task split action. Canal Studio
shares Save/export/checked-view commands across menus, toolbar, split action
and nested search. Rebinding updates every hint; rejected checks leave host
state unchanged. Todo's 36 tests, connected-surface tests, rendering and native
light/dark flows pass, including the existing import/Undo regressions. See
[verification](../verification-command-workflow.md). Example data and execution
remain host-owned and in memory.
Included in the [1.0.28 release qualification](../verification-release-1.0.28.md).
