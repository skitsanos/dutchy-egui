# DS-028 — Ledger verification audit of DS-001 to DS-026

Status: Resolved · 2026-11-07

## Problem

The ledger's 26 entries recorded checks, test counts, geometry, behaviors,
and native evidence that had not been independently re-verified against the
1.0.15 code, the frozen web reference, and the running demo site.

## Remediation

Re-run the required checks; verify every claim component by component
against the source, the tests, the live web components at the frozen
revision, the computed styles of `http://localhost:4545/`, the stored
baselines, and the native showcase; register each discrepancy as its own entry
without rewriting the records under review.

## Resolution

Executed on 2026-11-07 at 1.0.15 (`e5d60a0`). `cargo fmt --all --check`, the
three required Clippy configurations, `cargo test --all-features` (10 unit,
290 integration, 1 doctest), and `cargo test --no-default-features` pass.
Rustdoc with denied warnings, `cargo check --lib --target
wasm32-unknown-unknown` with and without features, and `cargo package --list`
succeed; `cargo update --dry-run` finds only transitive patch updates. All 14
palette tokens round correctly from their HSL sources and equal the demo
site's computed colors byte for byte; DS-003's four ratios reproduce exactly.
Historical test counts (16, 35, 44, 55, 65, 76, 96) match the release commits.
The web checkout is three commits past the frozen revision, touching only
SEO and routing files, so the appearance and behavior reference is unchanged.
Every source, test, and example file is below 400 lines, and `.clippy.toml`
enforces the complexity threshold of 15.

Verified: the functional claims of DS-001 to DS-026 (geometry, behaviors,
accessibility names and roles, host-owned state, test coverage) against the
code and tests, and the 1x/1.5x/2x baselines against the corresponding demo
pages. Not verifiable from the repository: native macOS, screen-reader,
Windows/Linux, and live-provider evidence, branch names, and the pre-commit
states described in DS-004, DS-013, DS-017, DS-019, and DS-020. The native
showcase was launched from a temporary app bundle and inspected in light and
dark mode across its pages; accessibility presses navigate it, and the DS-038
snap-back reproduced live.

Discrepancies registered: DS-027 (status and accent text contrast), DS-029
(tooltip source), DS-030 (stats and empty states), DS-031 (palette repaint
and focus), DS-032 (uppercased accessible names), DS-033 (alerts and
