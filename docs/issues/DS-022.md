# DS-022 — Optional HTTP image loading and live provider examples

## Problem

The initial image milestone accepted egui URI sources but required applications
to install all network/codec infrastructure. Online photos were therefore not
usable out of the box, and the showcase only demonstrated retained textures.

## Remediation

Add the optional `url-images` feature using current stable ehttp 0.7.3 and image
0.25.10, with original repository-owned texture-loader/cache code. Default builds
retain egui as their only direct runtime dependency. Installation is idempotent;
custom resource limits can be registered before the standard installer.

Fetch HTTP(S) asynchronously, follow redirects, identify PNG/JPEG by signatures,
and upload finished images in the UI pass. Bound streamed bytes, decoded pixels,
renderer dimensions, cache entries and concurrent work. Cache failures, expose
explicit host retry, protect visible textures from eviction, ignore forgotten
callbacks, and wake egui when work completes. Cancellation retains its permit
until the transport exits.

Add a shared Picsum source switch and reload to all three media pages. Verify
subjects/photographer metadata and link to the original photos. Keep offline
artwork as the initial source and distribute no third-party photographs.

## Resolution

Implemented locally for 1.0.13. Eight deterministic HTTP tests cover PNG/JPEG,
redirects, deduplication, failures/retry, byte/pixel/texture limits, body timeout,
concurrency, stale work, eviction and custom installation. Rendered HTTP workflows
cover keyboard gallery/lightbox navigation, retry recovery, actual texture pixels
and three themes/scales. Native macOS verification displayed live Picsum photos,
reloaded the collection and navigated the viewer. See [verification](../verification-url-images.md).

Limits remain explicit: ehttp's timeout applies to native response-body reads,
not connection/headers or browser fetch. Browser CORS/runtime acceptance,
authenticated requests, strict end-to-end cancellation and other codecs remain
outside this integration. No commit, push or registry publication was performed
for 1.0.13.
