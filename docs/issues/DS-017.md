# DS-017 — Keep confirmation actions on one row

Status: Resolved · 2026-11-06

## Problem

The archive confirmation showcase used the default 448-point dialog. Its two
standard-size actions exceeded the footer's available width and wrapped onto
separate rows at desktop widths.

## Remediation

Use the existing Medium modal width token (512 points) for this confirmation.
Keep the footer's wrapping layout and viewport width constraint.

## Resolution

The archive confirmation now opens at 512 points on wide viewports, with Cancel
Archive and Archive Project on one row. The library's default modal width is
unchanged. Smaller viewports still constrain the dialog and allow action wrapping.

The rebuilt native dark-theme showcase was inspected at 2x display scale and
confirmed the inline actions. Formatting, the full-feature suite, and all three
required Clippy configurations pass; see
the confirmation workflow test in `tests/overlay_rendering.rs` and the overlay
baselines (the generated log under `target/visual-proof/` is not retained).
No dependencies changed.
