# DS-012 — Implement menus and dropdown interaction patterns

Status: Resolved for this step · 2026-11-06

## Problem

The interaction milestone lacked grouped actions, anchored/context dropdowns,
editable selection, and command search. Reusing bare egui menus would leave
Dutchy geometry, destructive/disabled states, keyboard behavior, and host-owned
state contracts inconsistent.

## Remediation

Build small repository-owned adapters over native responses, Popup, ScrollArea,
TextEdit, and Modal. Share row painting and search navigation. Use stable action
keys, token geometry, accessible groups/listboxes/dialogs, explicit action and
commit results, and native input blocking. Keep application state and execution
in the host. Document scope and keyboard differences.

## Resolution

Version 1.0.7 adds `Menu`, `Dropdown`, `SearchableSelect`, and `CommandPalette`,
with public-API showcase pages. Menus support groups, separators, shortcut hints,
icons, disabled actions, and destructive intent. Search separates the active
candidate and editable query from committed selection. The palette supplies an
optional Cmd/Ctrl+K shortcut and restores focus after the native modal layer clears.

Interaction checks cover native/assistive/pointer actions, keyboard navigation,
disabled skipping, stable IDs, filtering, no-match status, popup bounds,
dismissal, focus confinement, and host state. Twelve rendering baselines cover
light/dark surfaces at 1x/1.5x/2x, plus desktop/narrow showcase previews. Native
macOS review confirmed actions, editable selection, command activation, and
corrected a duplicate dialog node so the named modal contains its editor/results.
Search painting now gives one active candidate even under a stationary pointer.

No dependencies were added. Context menus attached to already-rendered responses
dismiss to their target on Tab; the next Tab follows native host order. Nested
submenus, menu bars, checked actions, fuzzy/async search, and general modal/drawer
APIs remain outside this step. Native checks ran on macOS only, without a
running screen reader; broader platform/screen-reader acceptance remains open,
and source-palette contrast stays with DS-003.
