# DS-079 — Coverage matrix split before the Markdown rows

Status: Resolved in 1.0.26 · Priority: P4 · 2026-11-09

## Problem

Since the 1.0.24 integration, `docs/coverage.md` has had a blank line between
the Toolbar row and the Markdown row. A blank line ends a Markdown table, and
the two rows that follow carry no header or delimiter row, so renderers show
Markdown and CodeBlock as a paragraph of literal pipes instead of matrix rows.
Found during the independent review of the DS-073 to DS-076 work, whose new
MenuBar row sits above the blank line and therefore renders correctly.

## Remediation

Remove the blank line so the Markdown and CodeBlock rows rejoin the matrix.
When rows are appended in future, keep the table contiguous.

## Resolution

The blank line is removed on `docs/review-ds073-076`; the matrix is one table
again and no row text changed. The menus work inserts its MenuBar row directly
above the same spot, so the release merge resolves one adjacent-line conflict
in this file.
