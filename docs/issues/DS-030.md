# DS-030 — Stat tiles and empty states differ from the live components in detail

Status: Resolved · 2026-11-07

## Problem

Compared with `src/components/StatsGrid/index.tsx` and
`src/components/EmptyState/index.tsx` at the reference revision, the port has
small differences that `docs/stats-empty-states.md` does not record:

- Regular tile padding is always 24 points (`Stat::tile` in
  `src/widgets/stats/mod.rs`); the web uses 24 below 640 px and 32 above.
- Regular values use 36/48 points by tile width; the web steps 30/36/48 by
  viewport. The guide documents 36/48 without noting the dropped 30-point step.
- Labels on Dark and Primary tiles are painted at full inverse opacity
  (`src/widgets/stats/style.rs`); the web uses 60 % and 70 % opacity.
- Compact labels use the regular weight; the web compact label is bold.
- Trends: the web colors every non-negative sentiment success, draws a double
  chevron, and uses a 6-point gap. The port defaults to a muted `Neutral`
  (documented), draws a single arrow, and uses a 4-point gap
  (`src/widgets/stats/trend.rs`). The guide records the neutral default but not
  that the web default is success.
- Compact rows wrap at 160 points and leave empty bordered slots on a partial
  row (`src/widgets/stats/grid.rs` shares one `chunks`/`columns` path for both
  layouts); the web compact row is a single non-wrapping flex row.
- Empty state: the description-to-actions gap is 32 points (24 plus item
  spacing) against the web's 24; the table variant uses the shared 24/8/32
  rhythm instead of the spec's 16/4/16; the title is clamped to the 384/448
  text width while the web clamps only the paragraph.

Icon tiles (64/48/80), heading sizes, the dashed dashboard border, button
variants, Container widths, and Flex gaps match the live components.

## Remediation

Either align the values with the live components (32-point padding on wide
tiles, a 30-point value step, 60/70 % inverse labels, bold compact labels, a
6-point trend gap, a 24-point action gap) or record each as intentional in the
guide. Weigh the inverse-label opacity against DS-003 before adopting it.

## Resolution

Resolved in 1.0.16. Aligned: compact labels use the bold face, the trend arrow
sits 6 points before its text (`metrics::TREND_GAP`), and the empty-state
description-to-actions gap renders as 24 points (`tests/stats.rs`,
`tests/empty_states.rs`). Recorded in `docs/stats-empty-states.md` as
intentional: 24-point tile padding at every width, the 36/48 value steps, full
inverse label opacity (per DS-003), the single arrow and neutral default, the
wrapping compact row, the shared table-variant rhythm and the shared title
clamp. The insights baselines were refreshed.
