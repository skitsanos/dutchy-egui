# DS-025 — Scribble with host history and portable exports

## Problem

The advanced inventory lacked a drawing/signature surface. The web Scribble
combines freehand drawing, clear and PNG preview/export, but a library port must
retain completed data outside transient egui state and preserve it through DPI,
layout and theme changes. File saves and expensive encoding must stay host-owned.

## Remediation

Add modular, repository-owned vector data, capture, keyboard, painting, toolbar
and export helpers. Bind a stable-ID canvas to a bounded host drawing, with
captured brushes, single-point dots, undoable clear and immutable snapshots.
Provide keyboard drawing and named Canvas metadata alongside native controls.
Guard modal/clip/disabled states, model replacement, focus loss, resize and
repeated layout passes. Keep paper/ink and geometry in shared tokens.

Return ordered history/export requests. Supply static SVG and bounded CPU raster
output, with independent optional PNG encoding through the existing image codec.
Preflight pixels and sampling work before allocating large outputs. Keep UI
chrome/drafts out of exports and composite translucent joins once per stroke.
Demonstrate host workers, native Save As, failure feedback and retained previews.

## Resolution

Implemented locally for 1.0.15 after 1.0.14 was pushed as `cc10183`. Model/export,
pointer/keyboard/lifecycle, host workflow and theme/scale/narrow rendering tests
cover the new API. The narrow test exposed an ID-scope wrapping issue; toolbar
buttons now allocate directly in the wrapping layout while retaining stable
explicit widget scope/order. A sibling-insertion regression also verified that
toolbar IDs and keyboard focus survive reflow. Fractional export dimensions share uniform scaling and full
background coverage between SVG and raster output.

Default runtime dependencies remain egui only; `png-export` enables image 0.25.10
PNG without HTTP/JPEG or fonts. No helper/widget source was copied. Pressure,
tilt, multitouch, erasing, smoothing and history serialization remain outside
scope; native epaint and export edge rasterization are not pixel-identical.
Native macOS drawing, history, previews, SVG/PNG Save As, cancellation and keyboard
focus return were verified on 2026-11-07. Editable canvases now lock arrow focus;
a split-event-frame regression covers the native behavior. The host defers picker
focus until export work re-enables its opener, preserving intervening focus changes.
Remaining platform limits are recorded in [verification](../verification-scribble.md).

Post-push cleanup removed 15.3 GiB of artifacts and the merged file-upload branch;
the sole active worktree and unmerged work were preserved. Version 1.0.15 is
qualified for the user-authorized main release.
