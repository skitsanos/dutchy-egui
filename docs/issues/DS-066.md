# DS-066 — MediaCard titles run under the direction arrow

Status: Resolved in 1.0.24 · 2026-11-08

## Problem

`MediaCard` reserves `ICON + GAP` points at the right of the title row for the
direction arrow and lays the title job out at that narrower width, but then adds
it through `egui::Label::new(job).wrap()`. egui's `Label` replaces a wrapped
job's `wrap.max_width` with the full available width, so a title long enough to
fill the row extends under the arrow glyph. The narrow-card proof written by
`long_card_copy_wraps_within_a_narrow_column` (`target/collection-proof/
narrow-card.png`, 200-point card) shows "AN UNUSUALLY" colliding with the arrow;
that test only asserts that galleys stay inside the column, so it passes.

Found on 2026-11-08 while fixing DS-063. Short titles in the tracked
`collection-*` baselines and the showcase are unaffected.

## Remediation

Lay the title out to a galley at the reserved width and add it with
`Label::new(galley)`, which keeps a finished galley's wrap width, or route the
title through `text::add_ragged` with a width parameter. Extend the narrow-card
regression to assert that every title row ends left of the arrow rectangle, and
refresh any collection baseline whose title wraps differently.

## Resolution

`text::add_measured` lays a job out at its own wrap width and hands the finished
galley to egui's `Label`, so the width is no longer replaced; `add_ragged` now
builds on it for justified layouts, and MediaCard titles use it directly with
the width reserved beside the arrow. The narrow-card regression
`long_card_copy_wraps_within_a_narrow_column` (`tests/collection_rendering.rs`)
now asserts that the title's right edge stays left of the arrow column; it failed
on the reviewed tree (title ending at 172 points against an arrow starting at
158) and passes after the change. Short titles in the tracked `collection-*`
baselines lay out identically, so no baseline changed. Evidence for the original
defect: `src/widgets/media/card/paint.rs` (`title` reserved `ICON + GAP` for a
job that `Label::new(job).wrap()` then re-measured at the full width), egui 0.37
`Label::layout_in_ui` (`layout_job.wrap.max_width = available_width`), and the
narrow-card proof image.
