# DS-029 — Tooltip geometry follows the Markdown spec, not the live stylesheet

Status: Resolved · 2026-11-07

## Problem

The [reference decisions](../reference.md) name `src/styles/dutchy.css` and the
rendered localhost site as the appearance reference. The tooltip was measured
against `docs/01-design-system/components/tooltip.md` instead, and the two
disagree:

| Property | Live stylesheet | Markdown spec | Port (`src/tokens/tooltip.rs`) |
| --- | --- | --- | --- |
| Padding, vertical / horizontal | 6 / 12 | 6 / 10 | 6 / 10 |
| Maximum width | min(256, viewport − 32) | none (`nowrap`) | min(320, viewport − 20) |
| Letter spacing | 0.02 em | none | none (`Tracking::Normal`) |

Fill, text color, the 12-point medium face, the 8-point gap, and the 5-point
arrow match both sources. `docs/tooltips-layout.md` states that the
"10/6 padding … match the reference"; that holds for the Markdown file only.
The guide also presents the 320-point text width as a port value without
noting the 256-point source cap. `Tracking` has no 0.02 em step, so the live
letter spacing cannot be expressed with the current typography tokens.

A smaller behavioral gap: Escape pressed during egui's hover delay is not
recorded, because `src/widgets/tooltip/mod.rs` stores the dismissal only once
the popup has been requested. A hint can therefore still appear after the delay.

## Remediation

Decide which source governs tooltips. If the live stylesheet, set the
horizontal padding to 12, the maximum width to 256 constrained to the viewport
minus 32, add a 0.02 em tracking value (a `Tracking` step or a tooltip-local
token), and refresh the layout baselines. In either case, correct the guide so
it names the source it matches. Optionally record Escape during the hover delay.

## Resolution

Fixed in 1.0.16. The live stylesheet governs tooltips: horizontal padding is
12 points, the text width is capped at 256 points and at the viewport width
minus 32, and the text carries a tooltip-local 0.02 em letter spacing
(`TRACKING_EM`, since the shared `Tracking` steps have no such value).
`tests/tooltips.rs` measures the wide and narrow cases and reads the painted
letter spacing. `docs/tooltips-layout.md` now names the stylesheet as the
source, lists the Markdown values that are not used, and records that Escape
during egui's hover delay is not remembered. The layout baselines were
refreshed.
