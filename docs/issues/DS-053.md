# DS-053 — Calendar month buttons have invisible chevrons

Status: Resolved in 1.0.20 · 2026-11-07

## Problem

The native calendar exposed Previous/Next month buttons but painted no visible
arrows. Their eight-point icon rectangles were shrunk by the shared four-point
inset on both sides, collapsing each three-point path to one position. The
initial calendar snapshot encoded the defect.

## Remediation

Use the shared 20-point control indicator rectangle before applying the
navigation inset. Preserve button hit targets, names and disabled behavior.

## Resolution

The focused rendering regression in `tests/calendar_limits.rs` requires both
chevron paths to have visible width and height. It failed before the fix.
Only the new open-calendar baseline needs an intentional refresh; pre-existing
baselines remain intact. Native verification and final checks are recorded in
the follow-up report.
