# DS-115 — Showcase navigation and Todo task focus

Status: Resolved (unreleased) · 2026-11-11

## Problem

Showcase's desktop sidebar exposes each page as a separate Tab stop and has
no type-ahead. In DutchyTodo, keyboard navigation or completion can move the
focused task outside the visible list.

## Remediation

Use a single-select List for the desktop catalog. Keep the foundation pages
first, the footer pinned, and the wrapped buttons at narrow widths. Reveal
newly focused or reordered Todo rows and draw the row focus outline inside
its bounds. Keep task completion a separate checkbox action.

## Resolution

The desktop list has one Tab stop. Arrows and type-ahead select and reveal
pages, and manual scrolling preserves focus. Todo keeps separate checkbox
semantics and reveals the focused row when its position changes.

Integration tests cover desktop and narrow navigation, offscreen pages,
the pinned footer, and task focus after completion. Native macOS input
confirmed Tab, arrows and type-ahead in Showcase and End and Space in Todo.
