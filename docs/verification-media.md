## Limits

Textures work directly; URI/encoded-byte sources require host-installed loaders.
The library performs no codec installation, network/file I/O, retry execution,
texture lifetime management or cache eviction. Hosts retain handles and own
decoded-resource/cache limits. Collections are nonvirtualized; bound large slices.
Zoom/pan, slideshow timers, swipe/masonry, drag reorder, downloads/export and
animated-format acceptance remain outside this step.

Native GUI execution is macOS-only without an active screen reader. Windows/
Linux GUI, browser WASM execution, real codec/network integrations and a Rust
1.95 minimum-toolchain run remain outstanding. Metadata tests/native inspection
do not establish screen-reader acceptance, browser/whole-system parity or blanket
contrast compliance; inherited palette limits remain in [DS-003](issues/DS-003.md).
